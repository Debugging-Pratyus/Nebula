# Planetary Texture Assets Attribution

The planetary textures in this directory are based on NASA imagery and provided by **Solar System Scope** under the Creative Commons Attribution 4.0 International License (CC BY 4.0):
https://www.solarsystemscope.com/textures/

Credit: Solar System Scope / NASA / JPL-Caltech.
License: https://creativecommons.org/licenses/by/4.0/

Included assets:
- `sun.jpg`: Sun photosphere texture map
- `mercury.jpg`: Mercury surface terrain map
- `venus.jpg`: Venus dense cloud atmosphere map
- `venus_surface.jpg`: Venus radar topography surface map
- `earth.jpg`: Earth day diffuse surface map
- `earth_night.jpg`: Earth night city lights emissive map
- `earth_clouds.jpg`: Earth atmospheric cloud layer with alpha
- `mars.jpg`: Mars iron-oxide terrain and polar caps map
- `jupiter.jpg`: Jupiter cloud bands and Great Red Spot map
- `saturn.jpg`: Saturn pale gold atmosphere map
- `saturn_ring.png`: Saturn ring opacity and color gradient map
- `uranus.jpg`: Uranus aquamarine ice giant atmosphere map
- `neptune.jpg`: Neptune cobalt storm atmosphere map
- `milkyway.jpg`: Deep space Milky Way panorama map
